BI2 · DATA & STATISTICS

Levels of measurement PP Nominal labels only, no order (colour, gender) · Ordinal ranked, gaps unequal (Likert, grades, age brackets) · Interval differences meaningful, no natural zero (year, °C) · Ratio natural zero, ratios meaningful (price, weight, age). Qualitative = nominal/ordinal (discrete/continuous N/A). Quantitative = interval/ratio → discrete = counted (customers, pulse beats) · continuous = measured (time, height, temperature). Time series = one thing at regular time intervals; cross-sectional = many things at one time.

Centre mean x̄ = Σx/n (outliers skew it) · median = (n+1)/2-th sorted; even n → average the 2 middle; not affected by extremes · mode = most frequent (1 = unimodal, 2 = bimodal); good for nominal/ordinal · midrange = (min+max)/2.

Spread range = max − min · s² = Σ(x−x̄)²/(n−1) = [Σx² − (Σx)²/n]/(n−1) · s = √s² (calc: use sx/σn−1, not σn) · Q1 = (n+1)/4-th, Q3 = 3(n+1)/4-th sorted value; position not whole → average the two neighbours (2.75th → avg of 2nd & 3rd) · IQR = Q3 − Q1. Larger SD = more risk/variation.

Frequency table PP tally each value into its class → relative f = f/n → cumulative f = running total (last = n) → cum. relative = cum f/n. Class width = difference of consecutive lower limits = range ÷ no. of classes (round up); midpoint = (lower+upper)/2. Classes: <50 obs 5–7 · 50–200 7–9 · 200–500 9–10 · 500–1000 10–11. Cumulative chart (ogive): x = upper class limits, y = cumulative f; join points; never falls; label axes. "≤ k" → read the cumulative f.

Shape symmetric: mean = median = mode · positive/right skew (tail right): mode < median < mean · negative/left skew: mean < median < mode (mean chases the tail). Normal: bell, unimodal; ±1 SD 68.27%, ±2 SD 95.44%; 95% within ±1.96 SD; basis of t-test, ANOVA.

Statistics = collection, organisation, presentation, interpretation of data. Parameter ↔ Population; Statistic ↔ Sample. Descriptive (summarise: centre, dispersion) vs inferential (estimate: point/interval; hypothesis test; generalise sample → population).

Sampling population; census (everyone); sample; sample unit; sample frame = master list; frame error = list misses people. Probability: known (usually equal) chance → unbiased, representative, can generalise. Non-probability: unknown chance → quicker, cheaper, biased.
Simple random: random-number table; equal chance. Systematic: list + random start + skip interval = N/n (100 000/1 000 = 100; start 23 → 23, 123, 223). Stratified: strata homogeneous inside, different between; random sample in every stratum (proportional or weight). Cluster: clusters similar to each other, heterogeneous inside; pick a few clusters then census/sample (area sampling; 5 of 30 Park'n Shops) → cheap.

Steps ① H0, H1 ② choose test ③ α (usually 0.05) ④ compute t ⑤ critical value from t-table (df, α) or p-value ⑥ compare ⑦ |t| > tcrit (or p < α) → reject H0, else do not reject ⑧ conclusion in the context. Still unhappy? statistical ≠ practical significance (only +2 points; cost; no control group). Independent (caffeine): 9.778 vs 15.1, SD 4.1164/4.2805, n 9/10: SE = √(4.1164²/9 + 4.2805²/10) = 1.93; t = −5.322/1.93 = −2.758; df 17; 2.758 > 2.11 → reject.

Write-up H0: μd = 0; H1: μd > 0 → "paired t-test, same subjects measured twice" → α = 0.05, df = n − 1 → t = … → critical value … → "since t > critical, reject H0" → "there is significant evidence that …". Not rejecting ≠ proving H0 true.

Errors Type I (α) reject a true H0 (convict the innocent); α = significance level, set by researcher. Type II (β) fail to reject a false H0. Power = 1 − β. α and β inversely related for fixed n. High cost of Type I → smaller α. t/z-tests: only 2 groups, 1 independent variable → ANOVA for several groups.

A/B testing compare two versions (A, B) of a variable (web page, ad, e-mail, feature) on a metric (click-through, conversion); shows causal impact. Use when: clear hypothesis · sufficient sample · reasonable timeframe. Cycle: ① observe & design metrics (visitor records, heatmaps; conversion rate, average order value, subscription rate, CTR) ② construct hypothesis (H0: A and B same conversion rate) ③ sample size (thousands; baseline conversion rate + MDE: 20% & 5% → detect 19%/21%; smaller → underpowered) ④ run (random 50/50, fixed period e.g. 30 days) ⑤ analyse (inputs: visitors, conversions, one/two-sided, confidence; outputs: p-value, relative uplift, observed power) ⑥ act (winner → implement; inconclusive → new hypothesis).
Beware: 1 statistical vs practical significance (+0.1%) · 2 downstream metrics (upgrade +10% but LTV −30%) · 3 local maximum (one variable at a time) · 4 insufficient sample/time, outlier events (holidays), wrong instrumentation, bugs.

BI5 · K-MEANS · APRIORI · RECOMMENDERS

K-means unsupervised; high intra-cluster, low inter-cluster similarity; disjoint, non-hierarchical; an EM algorithm (E = assign, M = update). ① pick K random centroids ② assign each point to the nearest centroid, d = √Σ(xᵢ − mᵢ)² ③ new centroid = mean of its points ④ repeat ②③ until assignments do not change. Elbow: SSE = Σclusters Σx dist(x, c)²; SSE falls as K ↑; choose K at the bend (slide: K = 5). Other: silhouette. Limits: K must be specified; differing sizes/densities/non-globular shapes; outliers skew. Uses: customer segmentation, image segmentation, news/gene clustering, anomaly detection. k-means divisive vs hierarchical agglomerative.

K = 2: A(1,1) B(2,1) C(4,3) D(5,4) E(1,2) F(4,4); start c₁ = A, c₂ = B. Table: point | d to c₁ | d to c₂ | cluster. Round 1 {A,E} {B,C,D,F} → centroids (1, 1.5), (3.75, 3). Round 2: B → d 1.12 vs 2.66 → moves: {A,B,E} {C,D,F} → (1.33, 1.33), (4.33, 3.67). Round 3: no change → stop. SSE = Σ squared distances to own centroid = 1.33 + 1.33 = 2.67.

Association rules (market basket) X → Y. support(X) = count(X)/N · support(X→Y) = count(X∪Y)/N · confidence(X→Y) = count(X∪Y)/count(X). Keep rules with s ≥ minsup and c ≥ minconf. Rules from one itemset: same support, different confidence. Two steps: ① frequent itemset generation ② rule generation. d items → 2d itemsets; rules 3d − 2d+1 + 1 (d = 6 → 602). Reduce candidates (M), transactions (N), comparisons (hash tree; 15 candidates → match 9).

Apriori principle: if an itemset is frequent, all its subsets are frequent ⇔ any infrequent subset → itemset not frequent (support is anti-monotone: s(X) ≥ s(Y) for X ⊆ Y). Algorithm: L1 → repeat: join Lk with itself (first k−1 items equal) → C(k+1) → prune candidates with an infrequent k-subset → count (scan DB) → eliminate infrequent → L(k+1). Rules: a k-itemset gives 2k − 2 rules; for the same itemset c(ABC→D) ≥ c(AB→CD) ≥ c(A→BCD). + simple; prunes with Apriori principle. − many candidates/high cost (low minsup, many items); poor on dense data.

Stable relationship = relational PP. Extended product model: product > physical item: maintenance, service, installation, training, warranties, delivery, image.

3 levels of RM L1 pricing incentives (transactional end) · L2 social bonds: personalisation & customisation (relationship end) · L3 structural solutions (FedEx order-tracking terminals). Relationship = trust, commitment, caring, honesty, communication, loyalty, reciprocity.

Customer-centric culture understand the journey · customer feedback in daily routines · executives listen to calls monthly · empower acts of kindness · measure trust & commitment. Human factors leadership · HR capacity · communication · cooperation · quality of front-line staff · expensive CRM skills. Culture blockers rigid reward standards · production orientation · foreign-based executives · "technology is CRM" · little customer involvement · no risk taking · top-down · internal competition. Interactions: manage the journey on every channel, support with information, customer-centric view, touch points, business rules, 360° view.

Acquisition likely responders · mass media · free samples for contact data · portals · reduce adverse selection · research-based offer · free switching · word-of-mouth. Retention only profitable customers (2% → 90% of profit) · rewards · programmatic bonds (events, tickets, samples) · humanistic bonds (trained personnel) PP · conversational marketing · moments of truth · preferential treatment · personalisation · customisation · cross-selling · up-selling · managing migration · transactional → relational buyers · profit drivers as segmentation · brand building · online management. Downward migration: dissatisfaction · better attribute mix elsewhere · life-stage change. Prevent PP: proactive monitoring (BI early warning) · relationship strengthening (personal banker, priority, fee waivers, exclusive events). Win-back selling to a lost customer beats a new one · lost through simple mistakes · re-establishing is cheaper · analyse price sensitivity & last purchases.

CRM3 · SEGMENTATION, TARGETING, VALUE

Pareto / iceberg PP top 20% of customers = 80% of profits (curve peaks ~250% at ~55% of customers → last half destroy value). 150–20 rule: top 20% generate up to 150% of profits; bottom 20% lose 100%. Tiered servicing low-cost methods for the 80% low-profit, high-cost personal service for the 20%. Steep value skew → VIP status, relationships, "surprises". Shallow skew → cut costs (automation, AI) to attract competitors' customers. Tiers PP: T1 premium top 20% (VIP, relationship manager) · T2 standard middle 30% (balanced, cross-sell) · T3 basic bottom 50% (chatbots, self-service).

Segment case PP 15m ① profit per customer = revenue − cost to serve ② segment profit = customers × that ③ total; % of customers & % of profit ④ rank by profit per customer; accumulate until 20% of customers ⑤ justify: high value + high retention → high CLV → differential (tiered) treatment. TechStyle: VIP 3 000 × 7 300 = 21.9M · Regular 45 000 × 2 350 = 105.75M · Social 52 000 × 820 = 42.64M · Bargain 35 000 × 230 = 8.05M · One-time 15 000 × 30 = 0.45M · total 178.79M. Top 20% = 30 000 = VIP + 27 000 Regular = 85.35M (47.7%); VIP + Regular = 32% of customers, 71.4% of profit. Low-profit segment: migrate (up-sell, loyalty, low-cost channel; future value; avoids bad word-of-mouth) or de-market (fees, minimum order).

Bricks (stores, kiosks) vs clicks. Always-a-share: easy switching → transaction marketing. Lost-for-good: high switching cost → relationship marketing; artificial lock-in: contracts, prepaid vouchers, year-end discounts, exclusive gifts. No segmentation mass production/marketing, one offering (monopoly: water, electricity; national security, geography, huge investment). 4 levels niche (narrow group, distinctive benefits, pays premium, small volume: B&O) · local (neighbourhood) · segment groups · individual = one-to-one PP. Customisation = customer active; personalisation = customer passive. BI for segmentation: data · cost & profit · potential · positioning · evaluation.

STP segment (find needs/groups) → target (choose those you can serve competitively) → position (customer-focused value proposition; a cogent reason to buy) → SCA. Positioning map: price × quality. Reposition when: competitor matches · preferences change · new products/AI · positioning error · survival/younger appeal. Modern org chart = inverted pyramid: customers top, front line, middle, top management.

CPV = total customer benefit (product, services, personnel, image) − total customer cost (monetary, time, energy, psychological) versus perceived alternatives. E1 efficiency (least cost) ↔ E2 effectiveness (CPV); 7 Ps; CPV delivery → SCA. 5 BI steps for CPV PP ① ask customers/collect data on attributes & performance levels sought ② classify & cluster the importance of attributes ③ assess company vs competitors on attributes against importance ④ analyse segments ⑤ repeat periodically (values change). Satisfaction: periodic surveys, complaints, follow-up calls; CPQ vs CPP → CPV. CRM + BI help acquire the right customer · craft the right value proposition · institute the best processes · motivate employees. Emotional appeals: fear · humour · animation · sex · music · fantasy & surrealism.

Social media strategy = channel for promotion/awareness; social CRM = use the interactions & data to build individual relationships and engagement.

CRM5 · MARKETING RESEARCH & SCALES

Data (raw fact at a time/place) → Information (answers a question; primary or derived) → Knowledge (causal if–then rules) → Expertise (huge integrated knowledge: ChatGPT) → Wisdom (creates new knowledge, predicts). Marketing research = designing, gathering, analysing, reporting data to solve a specific marketing problem: product · promotion · pricing · place research. Families: qualitative · mobile & social · sampling · neuromarketing (brain activity).

Techniques secondary data analysis (existing data) · experience surveys (knowledgeable people) · case analysis · observation (direct/indirect; + natural, real; − small, behaviour changes if aware) · focus groups (moderator, small group, unstructured; new ideas) · surveys (representative samples) · longitudinal (same sample repeatedly over time → changing preferences PP) · experiment (independent → dependent). Interviews: one-to-one, open, deep; − costly, slow, small sample. Primary = collected first time; secondary = already collected.

Life cycle (11) need → define problem → objectives → research design → information types & sources → methods of accessing data → data collection forms → sample plan & size → collect → analyse → communicate insights. Scales nominal (gender, yes/no) · ordinal (rank brands) · interval (1–10 rating, Likert agree–disagree, semantic differential bipolar adjectives) · ratio (age, times bought). Likert → lifestyle/opinion; semantic differential → brand/store image; Stapel −3…+3 → performance.

DO NOT SWAP · MCQ & T/F

Supervised (labelled: classification, regression) ↔ unsupervised (no labels: clustering, association) · linear regression (continuous y, line, least squares) ↔ logistic (binary class, sigmoid probability) · support (share of ALL transactions) ↔ confidence (share of X-transactions that also hold Y) · user-based (similar users, Pearson) ↔ item-based (similar items, adjusted cosine; still subtract the user's mean) · stratified (random in every stratum) ↔ quota (same proportions, not random) ↔ cluster (a few whole groups) · paired (same subjects, df n−1) ↔ independent (two groups, df n₁+n₂−2) · Type I false alarm ↔ Type II miss · interval (no true zero) ↔ ratio · parameter (population) ↔ statistic (sample) · up-sell (dearer/upgraded version) ↔ cross-sell (extra related product) · customisation (customer chooses) ↔ personalisation (firm tailors from data) · OLTP (run the business) ↔ OLAP (analyse it) · data mart (one subject) ↔ EDW (whole enterprise) · pre-pruning (stop early) ↔ post-pruning (cut after full tree) · overfit (train high, test low) ↔ underfit (too general) · explicit (ratings) ↔ implicit (behaviour) · efficiency (least cost) ↔ effectiveness (customer value) · statistical (not chance) ↔ practical significance (big enough to matter) · k-means needs K ↔ tree needs class labels · median, mode, IQR resist outliers ↔ mean, range, SD do not · primary (collected first time) ↔ secondary data (already exists) · always-a-share (easy switching) ↔ lost-for-good (high switching cost).
