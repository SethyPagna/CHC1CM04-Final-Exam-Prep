### C3 (6 marks)

(a) H0: the mean number of items is the same for the two designs (μA = μB). H1: the means are different (μA ≠ μB). Two-tailed, because the question asks for "a difference". (1)

(b) **Independent-samples t-test**, because the two groups are different visitors (two separate samples), not the same people measured twice. (1)

(c)


### D1 (14 marks)

**(a) Entropy of S (2 marks)**

Renew: 6 Yes and 4 No out of 10.

```
H(S) = −(6/10) log₂(6/10) − (4/10) log₂(4/10)
     = 0.442 + 0.529
     = 0.971
```

Formula with the right counts (1). Answer 0.97 (1).

**(b) Information gain (6 marks, 2 for each attribute: 1 for the branch entropies, 1 for the gain)**

Plan:

| Value | IDs | Yes | No | Entropy |
|---|---|---|---|---|
| Basic | 1, 2, 3 | 1 | 2 | 0.918 |
| Standard | 4, 5, 6, 10 | 2 | 2 | 1.000 |
| Premium | 7, 8, 9 | 3 | 0 | 0 |

Weighted entropy = (3/10)(0.918) + (4/10)(1.000) + (3/10)(0) = 0.275 + 0.400 + 0 = 0.675.
**Gain(Plan) = 0.971 − 0.675 = 0.30**

Usage:

| Value | IDs | Yes | No | Entropy |
|---|---|---|---|---|
| High | 3, 5, 6, 8, 9 | 5 | 0 | 0 |
| Low | 1, 2, 4, 7, 10 | 1 | 4 | 0.722 |

Weighted entropy = (5/10)(0) + (5/10)(0.722) = 0.361.
**Gain(Usage) = 0.971 − 0.361 = 0.61**

Complaint:

| Value | IDs | Yes | No | Entropy |
|---|---|---|---|---|
| Yes | 1, 4, 6, 9 | 2 | 2 | 1.000 |
| No | 2, 3, 5, 7, 8, 10 | 4 | 2 | 0.918 |

Weighted entropy = (4/10)(1.000) + (6/10)(0.918) = 0.400 + 0.551 = 0.951.
**Gain(Complaint) = 0.971 − 0.951 = 0.02**

**(c) Root (2 marks)**

Usage has the largest information gain (0.61 > 0.30 > 0.02), so **Usage is the root** (1).

```
                 Usage?
               /        \
           High          Low
   {3, 5, 6, 8, 9}    {1, 2, 4, 7, 10}
   all Yes → leaf     1 Yes, 4 No → split again
```

Correct branches with the IDs (1).

**(d) Finish the tree (3 marks)**

The High branch is pure (all Yes), so it is a leaf.

The Low branch has {1, 2, 4, 7, 10} with 1 Yes and 4 No. Its entropy is 0.722. Two attributes are left.

- Plan: Basic {1, 2} → No, No (entropy 0). Standard {4, 10} → No, No (0). Premium {7} → Yes (0). Weighted entropy = 0. Gain = 0.722 − 0 = **0.72**. (1)
- Complaint: Yes {1, 4} → No, No (0). No {2, 7, 10} → No, Yes, No (0.918). Weighted entropy = (3/5)(0.918) = 0.551. Gain = 0.722 − 0.551 = **0.17**. (1)

Plan has the larger gain, so the Low branch is split on Plan. Every new branch is pure. Stop.

```
                 Usage?
               /        \
           High          Low
            |             |
           Yes          Plan?
                     /    |     \
                Basic  Standard  Premium
                  |       |         |
                  No      No       Yes
```

Correct final tree (1).

As rules: IF Usage = High THEN Renew = Yes. IF Usage = Low AND Plan = Premium THEN Renew = Yes. IF Usage = Low AND Plan = Basic or Standard THEN Renew = No.

**(e) Prediction (1 mark)**

Usage = High → **Renew = Yes**. The tree does not look at Plan or Complaint on this path.
